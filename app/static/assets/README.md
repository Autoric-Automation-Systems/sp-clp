# Assets visuais

Coloque aqui os arquivos visuais da aplicacao.

## Pastas

- `logo/`: logo principal, favicon e variacoes da marca.
- `icons/`: icones usados no dashboard.

## Formatos recomendados

- Logo: `.svg` ou `.png` com fundo transparente.
- Icones: `.svg` preferencialmente; `.png` quando necessario.
- Favicon: `logo/favicon.ico` ou `logo/favicon.png`.

Depois que os arquivos forem adicionados, atualize o HTML/CSS para apontar para os nomes finais.
